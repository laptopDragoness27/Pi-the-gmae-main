PI-THE-GAME

Pi the game is a game made in Pico-8 about guessing digits of pi one at a time. The game will use a spigot algorhithm to generate one digit of pi at a time, hopefully in an efficient way.

Features:
-dynamic timely generation of digits of pi as the game runs to prevent lag
-timers for each digit of pi you guess, 5 seconds for each digit
-sound effects for many actions in the game

AI disclosure: AI was used once to aid in fixing the pi-generation algorithm.
